# isoPOS iShare Starter

此套件是 GitHub Pages + Jekyll + Pages CMS 起始網站。

目前測試網址設定：
- `url: https://isopossoft.github.io`
- `baseurl: /isopos-ishare`

未來正式切換到 `isoposishare.com` 時：
- `_config.yml` 改為 `url: https://isoposishare.com`
- `_config.yml` 改為 `baseurl: ""`
- `.pages.yml` 的 `media.output` 改為 `/assets/images`
