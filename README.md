# isoPOS iShare v2

第二版視覺已導入使用者提供的 isoPOS Logo。

## 本版重點
- 灰藍品牌色
- 正式 Logo / Symbol / Favicon
- 首頁 Hero 品牌視覺
- 首頁文章卡片顯示封面圖
- 無封面圖時使用 isoPOS 品牌預設圖
- Article Schema 增加 publisher logo、articleSection、keywords
- 保留 robots / sitemap / noindex 邏輯

## 上傳方式
將本 ZIP 解壓縮後，把內容上傳到 GitHub repository 根目錄並覆蓋同名檔案即可。
